What is a search?

Two ways of counting the same clicks. Press the actions a user would take and watch how OLX's presto count and the alternative logic diverge. The Search team is asked to pick one — it is the denominator of Successful Searches, CTR 40, CTR@1/@3, ZRR and Searches per session.

The rules behind the counters

OLX's daily_user_searches.searches counts every listing page view. The alternative logic counts distinct (session, search_id) pairs — and search_id is a hash of the query parameters, so identical queries share it.

user actionlisting events firedOLX search countalternative logic
runs a query, sees page 111 search1 search
scrolls to page 2, 3, 4+3+3 searchesstill 1

retypes a different keyword+1 (new search_id)+1 search+1 search

OLX: a search is every time a result page is rendered.
Alternative: a search is every distinct query a user issues within a visit.
